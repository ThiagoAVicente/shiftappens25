# Projeto do ShiftAPPens

Projeto realizado para o [ShiftAPPens 2025](http://shiftappens.com).
O propósito deste projeto é armazenar informações médicas essenciais numa aplicação Android que possam ser lidas por alguém em caso de emergência através da tecnologia NFC.
